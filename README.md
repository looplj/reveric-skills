## 使用

点击技能名称打开原仓库。在 Reveric 的技能导入入口粘贴仓库链接，扫描后选择需要的技能。一个仓库可能包含多个技能。

Reveric 当前导入 `SKILL.md` 和受支持的文本 `references/`。目录不以脚本依赖或内容兼容验证作为收录门槛；部分项目使用其他分发格式或专用工具，实际导入能力取决于客户端。收录不代表已验证所有工作流可在 Reveric 中运行。

## 维护目录

直接编辑 [catalog.json](catalog.json)，然后运行：

```bash
dart run tool/update_readme.dart
dart run tool/update_readme.dart --check
```

README 表格由目录生成，不手动编辑。`when_to_use` 保留在目录中供应用使用，不出现在表格里。工具只需要 Dart SDK，无第三方依赖。

新增条目和自有技能的方式见 [CONTRIBUTING.md](CONTRIBUTING.md)。
