# AIGC 影视特效提示词万能公式体系（打斗 skill 调用版）

>
将 UE5、Niagara、Flow Map、Chaos Destruction 等技术词转为可见的材质、运动与破坏过程，避免只堆术语。

## 1. 总原则与适用范围

本准则适用于人物、兵器、机甲、巨兽、火焰、水体、雷电、风压、爆炸、建筑破坏、法阵结界、粒子群、空间裂缝、召唤物、灵体和环境异变等特效。

所有特效都必须回答：

- 谁或什么触发了特效；
- 特效从哪里、以什么结构生成；
- 形态怎样变化、沿什么方向运动、速度如何变化；
- 使用了哪些可见的材质、粒子、拖尾或结构变化；
- 特效如何命中目标并把力量传给目标；
- 周围空气、水、地面、建筑、烟尘、云层和光照怎样响应；
- 最后如何减速、消散、碎裂、坍缩或留下残留。

不能只写“特效震撼、光效华丽、粒子很多”，也不能只罗列技术名词。

## 2. 核心总公式 F1

F1：特效对象 + 形态结构 + 生成过程 + 技术机制 + 运动规律 + 视觉表现 + 交互反馈 + 消散过程

每次生成特效时，内部必须按 F1 补齐以下内容：

1. 特效主体与触发动作；
2. 形态结构与空间层级；
3. 生成、蓄力、聚集、生长、勾勒、分裂、压缩或爆发过程；
4. 控制运动、材质和粒子的技术机制；
5. 方向、轨迹、速度、加速度、旋转、涡流、受力和生命周期；
6. 颜色、亮度、透明度、发光、纹理、边缘、拖尾和粒子细节；
7. 受击、位移、形变、裂纹、破碎、穿透、飞溅或冲击反馈；
8. 环境联动、镜头反馈、余波和收束消散。

最终提示词可以把这些内容写成自然中文句子，不必把“F1”标签直接展示给用户；但不能省略 F1 所要求的可观察过程。

## 3. 十个底层模块

### 3.1 特效主体

明确是谁或什么产生特效：人物、手部、兵器、弹体、机甲关节、巨兽、召唤物、法阵、地面、建筑或空间本身。

### 3.2 形态结构

说明特效外形和空间构成：弧线、刃状、柱状、球状、环状、流体、雾团、晶体、裂缝、分层立体结构或生物轮廓。

### 3.3 生成逻辑

说明特效如何出现：从一点聚集、沿轮廓勾勒、从地面生长、分裂成多股、压缩成高密度核心、瞬间爆发、逐层展开或由远及近传播。

### 3.4 材质系统

说明内部发生什么变化：纹理流动、透明度变化、发光增强、边缘侵蚀、冷却结晶、熔化、闪烁、折射、烟尘浓度变化。

### 3.5 运动系统

说明整体和内部的运动区别：主体前进或旋转，内部纹理独立流动；同时交代加速度、轨迹、曲率、涡流、牵引、阻力和惯性。

### 3.6 粒子系统

说明独立的火星、光点、水滴、碎片、烟尘、晶屑、金属屑、能量丝和残渣如何生成、飞散、碰撞并按生命周期消散。

### 3.7 物理反馈

说明特效作用在目标上产生什么：压入、击退、穿透、切开、凹陷、变形、裂开、断裂、飞溅、掀起、冻结或熔毁。

### 3.8 环境联动

说明冲击如何传入水面、地面、建筑、空气、雨幕、树木、烟雾和云层，并形成有方向、有先后的连锁变化。

### 3.9 时序与镜头

说明蓄力、加速、释放、命中、余波、消散分别发生在什么时间段，以及镜头如何特写、跟随、拉远、震动、变焦、运动模糊或展示尺度。

### 3.10 收束消散

说明特效最后怎样结束：减速、失去亮度、逐层溶解、碎裂坍缩、冷却凝固、烟尘散开、余波衰减、持续燃烧后熄灭或留下残留物。

## 4. 子公式 F2–F7

### F2：材质动态

指定材质 + Flow Map 流向 + UV Panning 速度 + 动态材质参数变化 + 边缘扰动 + 光照结果。

适用于火焰、水流、雷电表面、能量核心、法阵纹理、熔岩、冰霜和空间裂缝。必须写出材质怎样流、亮度怎样变、边缘怎样扰动，以及这种变化怎样照亮或染色周围环境。

### F3：粒子运动

生成位置 + Spawn 规则 + 初始速度 + 力场作用 + 生命周期 + 拖尾与消散。

适用于火星、光粒、水滴、碎石、玻璃、金属屑、冰晶、烟尘和能量碎片。粒子必须有来源、方向和寿命，不能凭空出现或无原因持续铺满画面。

### F4：立体结构

基础几何 + 厚度与多层结构 + 空间透视 + 独立运动 + 内部动态 + 深度光影。

适用于法阵、结界、能量球、空间裂缝、巨型光刃、旋涡、晶体柱和灵体轮廓。要锁定主体轮廓，同时让内部层、边缘层和粒子以不同速度运动。

### F5：爆发冲击

压缩蓄力 + 瞬时释放 + 传播方向 + 力度衰减 + 受击变形 + 环境破坏 + 余波。

适用于拳击爆能、冲击波、爆炸、火雨落点、雷霆命中、建筑破坏和终结技。必须交代接触点、传播方向、先后顺序和余波，而不是只写“发生爆炸”。

### F6：环境联动

能量源 + 作用范围 + 传播速度 + 受影响介质 + 物理响应 + 连锁变化 + 残留。

适用于地面裂解、潮汐、飓风、建筑倒塌、森林燃烧、雷雨、空间扭曲和大范围领域。近处先响应，远处后响应；介质不同，反馈方式也必须不同。

### F7：电影动态

预备动作 + 力量传递 + 加速度曲线 + 特效同步触发 + 镜头反馈 + 时间节奏。

适用于技能前摇、蓄力、突进、挥砍、投射、命中、爆发和结束。特效触发必须和角色动作、镜头变化、声音节奏同步。

## 5. 技术术语到可见结果的映射

技术术语只在它能解释画面结果时使用：

| 火焰 | Flow Map、Curl Noise、Emissive Mask | 热纹理向上流动，火舌卷曲，边缘发光，火星飞散，背景热浪折射 |
| 水与海啸 | Fluid Simulation、Surface Displacement、Collision | 水体流向和速度、表面起伏、碰撞飞溅、回流和水雾 |
| 雷电 | Beam Renderer、Noise Displacement、Emissive Pulse | 主干与分叉路径、跳跃、电弧抖动、闪烁频率和命中闪光 |
| 风与冲击波 | Vector Field、Refraction、Radial Force | 空气传播方向、环形扩散、背景折射、尘土和布料被推开 |
| 刀光拖尾 | Ribbon Renderer、Velocity Sampling、Flow Map | 按真实挥刀轨迹生成拖尾，宽度和长度随速度变化，转向时保留惯性 |
| 激光能量炮 | Beam Renderer、Emission、Spawn Burst | 核心光束、脉冲亮度、边缘喷溅、命中点闪爆和热浪 |
| 烟雾与云 | Volumetric Fog、Advection、Turbulence | 体积密度、被气流搬运、卷吸、扩散、翻涌和散开 |
| 岩浆 | Fluid Simulation、Emissive Mask | 高黏度流动、表面发光、冷却结壳、裂缝和蒸汽 |
| 冰霜结晶 | Growth Mask、Mesh Particles、Dissolve | 从接触点生长、晶体增厚、碎裂、融化或消散 |
| 法阵结界 | Mesh Geometry、Dynamic Material | 立体厚度、分层符文、旋转速度、内部纹理和折射 |
| 漩涡传送门 | Vortex Force、Depth Layering、Refraction | 多层深度、向心吸引、自转、空间折射和边缘收缩 |
| 灵体与兽魂 | Mesh Particles、Flow Map、Ribbon Trails | 生物轮廓逐步构建，内部能量流动，动作带拖尾且关节结构稳定 |
| 能量生物群 | Mesh Particles、Vector Field | 群体方向、队形、局部速度差、残影和群体拖尾 |

## 6. 八类对象专属公式

### 6.1 能量聚集

来源 + 吸引中心 + 汇聚路径 + 密度变化 + 内部压缩 + 亮度增长 + 环境响应。

示例逻辑：人物掌心成为吸引中心，周围粒子沿弧形路径汇聚并绕行，核心密度和发光逐步增强，烟尘和衣摆被牵引，随后压缩成能量核并释放。

### 6.2 流体运动

来源 + 流动方向 + 流速 + 涡流形变 + 碰撞飞溅 + 环境反馈。

适用于水龙、洪流、海啸、火焰、熔岩和烟雾。必须写出流速、转向、撞击后的飞溅或蒸汽，以及不同介质的反馈。

### 6.3 高速拖尾

运动主体 + 真实轨迹 + 速度采样 + 宽度长度 + 内部流动 + 衰减。

适用于刀光、雷枪、飞行角色、能量兽和高速突进。拖尾应服从运动轨迹，速度越快越长或越亮，转向时有惯性，随后断裂、变薄并消失。

### 6.4 立体法阵

基础几何 + 厚度 + 空间层级 + 生成顺序 + 独立旋转 + 内部纹理。

适用于法阵、结界、召唤门和空间门。先写骨架或符文如何出现，再写层级、厚度、旋转和内部流动，不能只写一个平面圆环。

### 6.5 爆炸破坏

冲击源 + 接触点 + 材料响应 + 断裂顺序 + 碎片动力学 + 次生破坏。

建筑、兵器和机甲必须按材料区分反馈：混凝土开裂、钢筋弯折、玻璃飞散、装甲凹陷、地面掀起、烟尘扩散。先接触点，后主体断裂，再出现碎片和次生坠落。

### 6.6 电弧雷暴

发光源 + 传输路径 + 分叉 + 闪烁频率 + 光照反馈 + 命中。

雷电应有主干、分叉和跳跃路径，闪烁要与动作同步；命中金属、地面或目标时产生局部闪光、热痕、电弧残留和周围光照变化。

### 6.7 自然异变

事件源 + 传播路径 + 不同介质 + 连锁响应 + 时间延迟 + 远景影响。

例如龙卷从地面尘土开始，再卷起树木和碎石，最后影响云层；近处先变化，远处延迟响应，远景变化不能早于能量传播。

### 6.8 神兽灵体

生物轮廓 + 构建顺序 + 结构约束 + 内部流动 + 动作 + 环境反馈。

先出现轮廓，再填充能量或墨色，头、躯干、四肢和尾部的连接要符合生物结构；奔跑、咆哮、扑击时，轮廓、内部流动、拖尾和地面冲击同步。

## 7. 六层复合公式

VFX = G + E + M + T + P + I

这是用于检查复杂特效的概念分层，不是物理计算式：

- G（Geometry）：主体造型和三维骨架；
- E（Emission）：发光轮廓和能量强度；
- M（Material Motion）：内部动态纹理；
- T（Trails）：运动轨迹和拖尾；
- P（Particles）：独立粒子和次级碎片；
- I（Interaction）：受力和环境反馈。

复杂技能至少要保持清晰的主体结构、独立的内部动态和可追踪的环境因果，再增加粒子和镜头冲击；不能用粒子遮住主体，也不能用满屏发光代替动作。

## 8. 通用母公式

生成特效提示词时，内部按下列字段填充：

【主体与触发】[特效主体] 位于 [环境]，由 [动作或事件] 引发 [特效类型]。

【形成结构】从 [生成起点] 通过 [聚集、勾勒、生长、分裂、压缩或爆发] 逐步形成 [轮廓、几何结构、空间层次]。

【运动技术】使用 [技术一] 控制 [组成部分]，使其按照 [方向、轨迹、速度、受力] 持续变化，产生 [可观察结果]。

【动态材质】使用 [技术二] 控制 [纹理、发光、透明度、形态]，形成 [指定色彩与材质效果]。

【粒子细节】使用 [技术三] 生成 [粒子或碎片]，按照 [速度、碰撞、阻力、重力、力场] 运动，并依据生命周期衰减。

【分层约束】主体保持 [指定参考轮廓]；内部材质、发光边缘、粒子和拖尾以不同速度独立变化。

【目标反馈】作用于 [目标] 时产生 [受击、位移、形变、破裂等]，按 [作用方向和接触位置] 传递力量。

【环境联动】冲击传递到 [水、地、建筑、空气、云层等]，先产生 [第一阶段变化]，再沿 [方向与范围] 引起 [连锁变化]。

【镜头时序】采用 [镜头运动] 同步展示 [蓄力、加速、爆发、撞击、余波]，控制震动与运动模糊。

【结束方式】最后以 [减速、消散、碎裂、坍缩、持续燃烧或余波] 收束，并保持运动惯性与时间连续性。

## 9. 打斗场景的强制调用规则

1. 法术、兵器、格斗、召唤、机甲、环境破坏和空间异变的每一个特效，都必须至少经过 F1；复杂特效再选择 F2–F7 和相应的八类对象公式。
2. 特效写入打斗分镜的动作链：起手或前摇 → 形成 → 加速或释放 → 命中/接触 → 目标反馈 → 环境联动 → 余波/消散。
3. 角色释放技能时，要把视觉触发绑定到具体动作，例如掌心聚能、兵器蓄势、脚下踏地、法阵展开、机甲关节锁定或巨兽咆哮，禁止没有来源的凭空特效。
4. 高速动作必须写出速度可视化：运动模糊、人物残影、流光拖尾、环境动态模糊或背景拉伸；拖尾和模糊必须服从方向、轨迹和速度。
5. 打击接触必须写出接触点和能量传递。元素能量爆发只在角色、技能或用户设定支持时加入，并说明它如何照亮目标、推动碎片、改变烟尘或破坏地面。
6. 大范围技能要写作用半径、传播方向、近远景先后和介质差异；不能只写“全场被覆盖”。
7. 特效不能遮挡角色的关键动作、表情和目标关系；主体轮廓优先，粒子、拖尾、烟尘和镜头震动服务于动作可读性。
8. 参照图锁定主体轮廓、关键纹理、颜色和材质；允许内部流动、发光边缘、粒子和拖尾独立变化，但不能改变角色、兵器或召唤物的身份。
9. 技术术语不是最终画面的替代物。最终提示词应以自然中文呈现可见行为、时序和因果关系；只有在能帮助模型理解目标结果时保留技术名词。
10. 每个特效必须有结束方式。没有持续燃烧、持续领域或残留设定时，不能让特效无原因地一直存在。

## 10. 特效质量检查

输出前逐项检查：

- 是否有明确的触发主体和动作；
- 是否有从生成到结束的过程，而不是只写最终状态；
- 是否有清晰主体轮廓、空间层次和方向；
- 是否分开描述整体运动与内部材质运动；
- 是否有粒子生成位置、速度、力场、生命周期和消散；
- 是否说明命中点、受击反馈、材料响应和环境联动；
- 是否有镜头时序、尺度展示、运动模糊或镜头震动的依据；
- 是否把技术术语转换成了可见结果；
- 是否保持参考图、角色、兵器、空间和相邻镜头连续；
- 是否使用了本打斗 skill 的速度、力度、镜头和时长约束；
- 是否在总输出不超过 5000 字符的情况下保留关键因果。

### 禁止项

- 只写“绚丽特效、震撼光效、粒子爆炸”；
- 只写技术名词，不写它控制的对象和可见结果；
- 只有平面纹理平移，没有主体结构和内部运动；
- 没有触发动作却凭空出现爆炸、雷电、火焰或裂缝；
- 没有接触点和传播方向的无因果击退；
- 只写命中瞬间，不写蓄力、生成、余波和消散；
- 用粒子、烟雾、强光遮住人物动作、目标位置或空间关系；
- 把 Flow Map 当成完整流体模拟，把任何引擎名当成模型一定会执行的命令。

## 11. 与 V6 输出字段的对应关系

- 场景与空间：主体位置、作用范围、介质、环境联动；
- 角色表演与动作：触发动作、前摇、力量传递、命中和反应；
- 镜头与运镜：F7 时序、蓄力特写、跟随、拉远、大全景、运动模糊和震动；
- 画面与特效：F1、F2–F6、六层复合公式和对象专属公式；
- 声音：蓄力低鸣、破风、爆发、撞击、材料断裂、余波和环境回响；
- 剪辑与连续性：上一镜头的残留、当前镜头的触发、下一镜头的余波与状态承接；
- 输出质检：公式完整性、可见结果、角色与环境一致性、时长和 5000 字符限制。

这套准则是特效模块的硬约束；如果用户明确要求写实、低特效、无特效或某种特殊风格，应尊重用户的强度要求，但仍以“有因果、可观察、可收束、保持连续性”的方式描述。
