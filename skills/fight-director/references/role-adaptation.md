## 11. 角色类型判断与战斗适配模块

角色模块位于风格组合器之前，负责判断“这个角色是谁、使用什么战斗手段、承担什么战斗职责、能力从哪里来”，再把判断结果传给打斗风格和战斗机制组合器。

角色名称不能作为唯一分类。必须把角色拆成三个相互独立的维度，避免“法师、召唤师、控制师”等职业名称互相覆盖。

### 11.1 三维角色战斗分类

#### 战斗手段：使用什么战斗

拳脚、剑、刀、枪、戟、斧锤、链鞭、弓弩、投射物、枪械、火炮、法术、异能、召唤物、机械装备、环境力量、空间/时间/因果等概念能力。

#### 战斗定位：承担什么职责

输出、坦克、辅助、控制、治疗、刺杀、远程压制、范围清场、召唤协同、阵地防守、战术支援、机动骚扰。

#### 力量来源：能力从何而来

修炼、魔法、神力、科技、血脉、契约、灵魂、药剂、装备、阵法、天地灵力、法则。

角色分析结果必须同时给出这三个维度。例如：

```text
战斗手段：毛笔、彩墨、画卷、法阵、墨兽
战斗定位：远程法术输出＋范围控制＋召唤物协同
力量来源：天地灵力＋召唤契约
```

### 11.2 12个基础角色战斗职业原型

每个基础职业都应维护：职业定义、细分职业、典型武器/技能、战斗距离、默认定位、能力来源、动作体系、技能特效、环境互动、推荐机制、适配风格和常见限制。

1. **格斗家系（Martial Artist）**：主要依靠身体素质、近身技巧、拳脚和体术强化。细分：拳斗士、武僧、拳法家、踢技师、摔投手、体术师、气功师、狂战士。
2. **法师系（Mage）**：以法术、能量操控、元素魔法或超自然力量为主要攻击方式。细分：元素法师、奥术师、咒术师、符箓师、雷法师、冰法师、时空法师、幻术师、血法师。
3. **兵器大师系（Weapon Master）**：专精各类近战武器，通过武器技巧、战斗姿态和武器技能攻击。细分：剑术师、刀术师、枪术师、长柄武器师、斧锤士、链鞭士、双刀流、棍术师、鞭术师。
4. **枪械与科技系（Gunner / Tech Specialist）**：以枪械、现代科技武器或未来科技装备为核心。细分：枪手、狙击手、炮术师、爆破专家、重装炮师、枪斗士、无人机操控师、机械工程师。
5. **弓弩与投射系（Archer / Ranged Specialist）**：使用弓弩、投射物或其他远程兵器，重视精准度、弹道技巧与远程压制。细分：弓箭手、神射手、弩手、投枪手、飞刃师、暗器师、弓术游侠。
6. **刺客与潜行系（Assassin / Rogue）**：擅长高速移动、隐身、偷袭、弱点攻击和精准刺杀。细分：刺客、忍者、影舞者、盗贼、暗杀者、毒刃师、幻影刺客。
7. **召唤与御兽系（Summoner / Beastmaster）**：通过召唤生物、灵体、傀儡或契约兽参与作战。细分：召唤师、御兽师、驭龙者、亡灵法师、傀儡师、式神使、精灵使、兽魂使。
8. **防御与守护系（Guardian / Tank）**：强调防御、护盾、阵地控制、承伤与保护队友。细分：圣骑士、盾战士、重甲骑士、守护者、结界师、壁垒战士、符文卫士。
9. **治疗与辅助系（Healer / Support）**：使用治疗、增益、净化、强化和特殊领域技能改变战局。细分：牧师、治愈师、圣职者、吟游诗人、祝福师、药师、炼金术师、阵法辅助师。
10. **诅咒与控制系（Debuffer / Controller）**：通过封印、毒素、诅咒、精神干扰和减益控制削弱敌人。细分：咒术师、封印师、毒术师、控魂师、催眠师、精神术师、禁锢师等。
11. **变身与强化系（Shapeshifter / Transformer）**：通过肉体异化、兽化、附身、觉醒或形态切换获得新能力。细分：德鲁伊、兽化战士、龙化者、魔化战士、狼人、巨化战士、附身术师、变形师。
12. **特殊法则与概念系（Reality Manipulator）**：操纵空间、时间、重力、因果、梦境等抽象能力，适合高概念幻想和科幻角色。细分：空间使、时间术师、重力使、梦境行者、镜术师、因果术师、念动力者、维度行者。

基础职业是角色识别的起点，不是最终限制。角色拥有明显跨系能力时，应生成复合职业，而不是强行归入单一职业。

### 11.3 混合战斗职业

混合职业由主职业、副职业和战斗定位共同生成。先选择承担主要攻防的能力，再按场景需要加入辅助能力。

| 混合职业 | 职业组合 | 核心战斗特点 |
|---|---|---|
| 魔剑士 | 剑术师＋法师 | 剑术与元素魔法结合 |
| 符剑师 | 剑术师＋符箓师 | 符文附剑、剑阵攻击 |
| 战斗法师 | 格斗家＋法师 | 近战体术与魔法连击 |
| 枪斗士 | 枪手＋格斗家 | 枪械与拳脚擒拿配合 |
| 机械召唤师 | 机械师＋召唤师 | 召唤机器人、机械兽 |
| 影武者 | 刺客＋幻术师 | 分身、隐身、高速刺杀 |
| 龙骑士 | 骑士＋驭龙者 | 骑乘巨龙进行空中战斗 |
| 神兽武者 | 格斗家＋御兽师 | 兽魂附体、神兽协同攻击 |
| 圣剑士 | 剑术师＋圣职者 | 神圣剑气、治疗与守护 |
| 炼金战士 | 兵器大师＋炼金术师 | 药剂强化、武器变形 |
| 画师/墨师 | 法师＋召唤师 | 画物成真、笔墨化战 |
| 时空剑士 | 剑术师＋时空法师 | 空间斩击、瞬移、时间减速 |

用户可以直接指定复合职业，也可以只描述能力，由 AI 生成可解释的复合职业名称。复合职业名称必须服务战斗设计，不得为了新奇而增加没有动作依据的能力。

## 12. 角色输入与判断模式

### 12.1 用户上传角色图

当用户上传角色图、角色立绘、参考资产或已有视频截图时，先提取可见证据：

- 武器、装备、护甲和道具
- 姿态、重心、握持方式和攻击准备
- 服装、职业符号、法阵、纹章和材质
- 机械部件、召唤物、能量形态和环境线索
- 角色体型、移动方式和可能的战斗距离

再将证据映射到基础职业、细分职业和复合职业。可见事实、用户文字和 AI 推断必须分开保存，不能把“看起来像法师”直接写成角色已经拥有某种法术。

识别结果应包含置信度：

```text
可确认事实：角色持有长枪，穿戴机械装甲。
推断职业：枪械与科技系。
可能细分：重装炮师或机械工程师。
推荐机制：热兵器型＋机械装备型。
置信度：高。
```

如果图像证据不足，采用最少新设定的近似职业；只有当不同判断会明显改变最终战斗设计时，才请求用户确认。

### 12.2 用户输入想要的角色

用户可以只提供一句角色创意，例如：

```text
我想要一个会用毛笔召唤墨兽的角色。
```

AI 应将其编译为：

```text
主职业：墨术师
副职业：召唤师＋阵法师
战斗手段：毛笔、彩墨、画卷、法阵、墨兽
战斗定位：远程法术输出＋范围控制＋召唤物协同
力量来源：天地灵力＋召唤契约
```

用户也可以只给战斗感受，例如“高机动、近身爆发、会隐身”，AI 应匹配刺客与潜行系，并补全影舞者、徒手/冷兵器、体术＋技能和精密近身攻防等标签。

### 12.3 用户指定与 AI 推断冲突时

遵循以下优先级：

```text
用户明确职业和能力
→ 用户上传资产中清晰可见的武器/道具
→ 用户明确的剧情和战斗结果
→ 角色外观和动作证据
→ 题材惯例
→ AI 默认补全
```

用户明确说“这是法师”，即使角色手持剑，也应保留法师身份，并将剑判断为法器、辅助武器或近战备用手段，除非用户要求改写角色。

## 13. 角色与打斗风格、战斗机制的联动

角色模块只负责提供推荐和约束，最终选择仍服从用户明确指定的风格组合。

- 格斗家系：优先徒手格斗型、体术＋技能型、变身强化型；适合写实格斗、热血动漫、武士剑道等风格。
- 法师系：优先纯技能型、元素法术、环境操控型；适合仙侠玄幻、西方魔幻、元素法术、黑暗奇幻等风格。
- 兵器大师系：优先冷兵器型、兵器＋技能型；适合武士剑道、古代战争、仙侠玄幻、西方魔幻等风格。
- 枪械与科技系：优先热兵器型、机械装备型；适合现代军事、科幻机甲、蒸汽朋克、赛博朋克等风格标签。
- 弓弩与投射系：优先冷兵器型、远程压制和环境利用；适合西方魔幻、古代战争、末日废土、神话史诗等风格。
- 刺客与潜行系：优先冷兵器型、徒手格斗型、体术＋技能型；适合写实格斗、黑暗奇幻、热血动漫、超自然异能等风格。
- 召唤与御兽系：优先召唤操控型、纯技能型、环境操控型；适合仙侠玄幻、神话史诗、黑暗奇幻、超现实概念等风格。
- 防御与守护系：优先冷兵器型、机械装备型、环境操控型；适合古代战争、西方魔幻、科幻机甲、神话史诗等风格。
- 治疗与辅助系：优先纯技能型、召唤操控型、环境操控型；重点设计增益、净化、护盾和战场改变，不强行改成纯输出角色。
- 诅咒与控制系：优先纯技能型、环境操控型、召唤操控型；适合黑暗奇幻、超自然异能、超现实概念等风格。
- 变身与强化系：优先变身强化型、体术＋技能型；适合热血动漫、超级英雄、巨兽怪兽、黑暗奇幻等风格。
- 特殊法则与概念系：优先纯技能型、环境操控型、多机制混合型；适合超自然异能、超现实概念、星际太空等风格。

用户指定组合时，按其能力设定设计动作和衔接。

## 14. 角色战斗档案

角色识别完成后，内部统一生成以下档案，供后续打斗分镜调用：

```text
【角色战斗档案】
角色名称：……
角色来源：用户上传 / 用户设定 / AI设计
可确认事实：……
主职业：……
副职业：无 / ……
复合职业：无 / ……
战斗手段：……
具体武器与道具：……
战斗定位：……
力量来源：……
战斗距离：近战 / 中程 / 远程 / 多距离
动作体系：……
技能体系：……
专属武器体系：……
战斗特效体系：……
环境互动方式：……
推荐打斗风格：……
推荐战斗机制：……
推荐动作及视觉表现：……
角色限制与弱点：……
识别依据与置信度：……
```

最终视频提示词只提取当前镜头真正需要的角色字段，不把完整分类档案全部复制进提示词。

## 15. 角色模块与组合器的完整链路

```text
角色图/角色设定/用户意图
→ 可见事实与能力线索提取
→ 12类基础职业判断
→ 战斗手段＋战斗定位＋力量来源
→ 主职业/副职业/复合职业生成
→ 角色动作、技能、武器和特效体系
→ 20种打斗风格匹配
→ 战斗机制匹配
→ 动作及视觉表现选择
→ 战斗分镜编译
```

角色层决定“这个角色怎么打”，世界观风格层决定“战斗看起来属于什么世界”，战斗机制层决定“力量如何产生和运转”，动作视觉层决定“观众如何看见这场战斗”。

## 16. 角色能力取舍

只选择本场冲突用得到的能力。每项能力都要改变距离、防线、主动权或结果；角色能力很多时，将其余能力留到后续场景。时间与正文篇幅按 [输出格式](output-format.md) 安排。
