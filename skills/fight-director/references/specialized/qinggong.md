# 高级轻功：支点、路径与落点

先确定动作尺度：写实动作使用地面、墙沿和稳定物体；武侠轻功允许夸张跃距、竹梢借力与短暂点水；仙侠飞行需另有持续支撑能力。每次转向说明依靠蹬踏、抓握、摆荡、受力或已设定的法术。

## 动作库

| 编号／动作 | 支点、轨迹与对手回应 | 镜头与承接 |
| --- | --- | --- |
| qinggong.01 贴地疾步 | 连续蹬地压低躯干，沿前方窄路逼近；对手退步让出距离 | 中景横跟脚下，结束时踏稳再出招 |
| qinggong.02 折线移位 | 以脚下制动切换斜向路线，绕开来袭直线；对手转身重找目标 | 斜俯中全景交代折点，不能省略刹停 |
| qinggong.03 侧跃离线 | 支撑腿蹬地向侧方跳出攻击路线，落地屈膝承重；对手追向新位置 | 全景保留起点与落点，落地后恢复防线 |
| qinggong.04 旋步绕柱 | 以近柱脚步作转向中心，从柱外圆弧绕到侧面；对手被柱遮挡片刻 | 中景随人绕障碍，镜头从空隙通过 |
| qinggong.05 矮墙翻越 | 手掌触墙沿支撑，双腿越过障碍后在另一侧落地；追击者选同路或绕行 | 中全景看掌触、跨越、落点，不把墙当空气 |
| qinggong.06 借墙横蹬 | 脚踏侧墙给身体横向推力，朝预先看见的平台跃出；对手攻击擦过原位置 | 全景同时包含墙与平台，踏点留下粉尘 |
| qinggong.07 连阶上跃 | 逐级踩上台阶或残墙，身体随每次蹬踏升高；追击者落后一个支点 | 侧斜跟拍，保持高度递增与台阶位置 |
| qinggong.08 飞檐横走 | 沿有宽度的屋檐连续落脚前行，瓦片因受力轻动；对手从屋脊切近 | 全景交代屋檐宽度，中景跟进脚下变化 |
| qinggong.09 屋脊跨越 | 屋脊端部蹬起跨向另一屋面，躯干沿弧线下降；对手在落区拦截 | 全景看两屋间距，落地有坡面减速 |
| qinggong.10 檐下悬停 | 跃起后双手抓住檐边，身体短暂下垂躲过上方攻击；对手沿檐查找 | 斜侧中景看握点、摆幅和手臂受力 |
| qinggong.11 悬檐翻上 | 由悬挂状态收腿抬身，借檐边支撑翻至屋面；对手后撤给自己留出招距 | 中全景延续同一抓握点，不能直接切成站姿 |
| qinggong.12 垂墙滑降 | 身体贴近墙面下降，以可见接触摩擦减速；上方敌人追到墙沿 | 侧面全景交代高度，落地屈膝吸收惯性 |
| qinggong.13 窄梁交错 | 沿梁前进时侧身让过对手，双方交换前后位置；梁因受力轻颤 | 斜俯全景交代梁宽与两人落脚，不能同时穿过彼此 |
| qinggong.14 绳桥回弹 | 角色踩在绳桥上使桥面下沉，借回弹跃到侧方桥柱；对手被桥晃动打断节奏 | 全景先见桥体变形再见起跳 |
| qinggong.15 吊索摆渡 | 先抓牢悬索，随绳长画弧摆向对岸；敌人移动到预计落点 | 全景看支点与绳长，松手后接抛物线下落 |
| qinggong.16 竹梢借弹 | 武侠模式下踩弯竹梢，竹身回弹时跃向相邻竹竿；对手追击使另一株竹弯曲 | 远中景保留竹的形变与落脚，不写实心空气支点 |
| qinggong.17 树干环步 | 脚踏树干侧面短促蹬转，身体绕树偏移后落地；对手的攻击撞上树皮 | 中全景看接触位置和回落，树皮碎屑沿受力方向飞出 |
| qinggong.18 枝间纵跃 | 连续使用已经出现的树枝作支点，跃距随枝条高度改变；对手选择下方抄近路 | 全景显示上下两条路线，枝条承重有反应 |
| qinggong.19 浮物连点 | 踩木板、船舷或浮石改变位置，浮物下沉或偏转；追击者被变化的落点迫慢 | 斜俯中全景逐个交代支点，不让浮物保持绝对静止 |
| qinggong.20 水面三点 | 武侠模式短暂掠过水面，每次触水带出独立水花，最后落到岸石；对手沿岸拦截 | 全景明确起岸与终岸，水花按路径依次扩散 |
| qinggong.21 浪脊借势 | 浪峰升起时短踏浪脊越过船舷，身体落到甲板；敌人在船体摇晃中架挡 | 全景把浪、船、角色放在同一运动关系中 |
| qinggong.22 断崖折返 | 先跃向对面凸岩，再蹬凸岩折回原岸更高处；追击者冲到崖边停住 | 全景先展示凸岩；中途换向必须发生接触 |
| qinggong.23 落差卸力 | 从高台落下先以脚接地，再顺势翻滚卸去速度；对手趁其起身追进 | 中全景连续跟落地、滚动、起身，不一帧恢复站姿 |
| qinggong.24 滑步回身 | 落地后利用已有滑行继续退开，前脚制动后转身面对追兵；追兵收招调整 | 中景跟随减速，地面留下连续摩擦痕 |
| qinggong.25 回落反击 | 从可见支点跃过攻势，下降时对准对手侧面出招；对手转身架挡，双方在落地后分开 | 全景交代下降方向，切中景看接触与落地重心 |

## 编排与检查

优先组合一条空间路线：起点 → 两三个支点 → 交锋点 → 终点。屋顶追逐可用连阶上跃、屋脊跨越、落差卸力；竹林用树干环步、竹梢借弹、回落反击；桥上交锋用绳桥回弹、吊索摆渡、滑步回身。

轻功不能与攻击互相脱节：改变高度后，对方要重新瞄准、追击、封路或失去视野。空间镜头至少让观众知道下一个可达位置；飞行时也保留加速、转弯与停下的原因。脚在水面、竹梢或墙上的接触只在相应世界观成立，不套入写实格斗。
