# 剑法：动作单元与风格映射

先确定剑身形制、持握手与实体数量。动作以身体、步法和剑的接触部位共同完成；剑气只附着在已经明确的剑路上。

## 动作库

| 编号／动作 | 动作、轨迹与对手回应 | 镜头与后续状态 |
| --- | --- | --- |
| sword.01 进步直刺 | 后脚推动重心向前，剑尖沿窄直线进入对方防线；对方侧步拨开，剑尖随之偏离 | 中景斜侧跟进，保留双方足下；刺空后收肘回剑 |
| sword.02 退步挂剑 | 退半步使来刃经过身前，剑身沿立圆挂开；对方兵器弹向侧面 | 近景看两刃接触，拉至中景交代退出距离 |
| sword.03 转髋上撩 | 下沉后转髋带剑从低向高走斜弧；对方抬械接住，双方短暂停在高位 | 中景看腰、剑和对手护架；接高位撤步或反向回收 |
| sword.04 腕控点剑 | 躯干稳定，前臂送剑后腕部短促下点；对方撤回兵器或抬柄挡开 | 近景突出剑尖小弧与目标变化，随后回中线 |
| sword.05 顺势劈落 | 举剑形成上方威胁，迈步带刃斜下落；对方移动退出斩线，剑刃扫过衣摆外侧 | 全身中景展示起落，不用火花假装命中 |
| sword.06 崩剑开线 | 以短促上挑改变接触点，把对手来剑托离原方向；对方顺势收回避免失衡 | 近景看剑身角度变化，下一拍回到可控距离 |
| sword.07 侧步截剑 | 向来剑外侧移步，剑身截在其运动路线上；对方减速收招，主动权短暂变化 | 斜侧中景同时看到脚步和交叉点 |
| sword.08 腕花护身 | 剑沿身侧连续画交替小圆，身体随步转向；对方等待空档而非被剑花自动击退 | 中景保留剑尖与身体轮廓，圆弧结束时回架 |
| sword.09 斜步横削 | 踏向侧前方，腰带剑作一条水平弧；对方压低重心从刃下退出 | 中景横移，结束时双方已错身，下一镜保留朝向 |
| sword.10 压剑转线 | 两刃接触后沿接触点轻压并转身，迫使对手移动持械手；对方退步脱离 | 近景短看摩擦，切中景解释两人距离 |
| sword.11 低身回锋 | 躯干下降让过高位挥击，剑从身侧回切兵器下方空档；对方缩步架低防线 | 斜俯中全景，动作结束时脚下踏稳再起身 |
| sword.12 跃步落剑 | 明确蹬地起跳，剑在下降时沿单一斜线落下；对方侧退，落剑在原位置留下浅痕 | 全景跟完整起落，落地屈膝收势再追击 |

## 编排与检查

九套风格的选择依据见 [兵器定位](../weapon-direction.md)。下面是组合建议，不要求还原整套套路：

| 风格标签 | 动作组合 | 画面重点 |
| --- | --- | --- |
| 太乙玄门 | 挂剑→压剑转线→直刺 | 圆转后收成一线，步法跟随剑路 |
| 六路总剑 | 低身回锋→跃步落剑→截剑 | 高低转换与完整落点 |
| 杨式太极剑 | 退步挂剑→压剑转线→点剑 | 连续柔和运镜，接触后再借势 |
| 独孤九剑 | 截剑→点剑→侧步直刺 | 对手先露出破绽，动作短而明确 |
| 华山基础 | 直刺→劈落→回架 | 清晰起收和简洁方向 |
| 玉女十九剑 | 斜步横削→腕花护身→点剑 | 轻盈转位，避免只剩光圈 |
| 白猿二十四剑 | 低身回锋→跃步→上撩 | 身体高低差与敏捷回收 |
| 青龙剑 | 横削→上撩→劈落 | 较大的弧线，场地留足挥动空间 |
| 峨眉子午剑 | 截剑→短直刺→退出 | 短距离变化，命中与落空都给反馈 |

近身碰撞优先看剑身、护手和持握变化；全身大弧不切成全程手腕特写。先排实体剑路，再叠角色主色的光轨。
