# 修仙剑招：实体剑、剑气与剑阵

先区分实体佩剑、受控飞剑和纯能量剑影，分别锁定数量、控制方式与持续时间。以近身剑路、远程轨迹或剑阵结构为主轴；大规模特效仍有起点、方向、对手应对与环境余波。

## 动作库

| 编号／动作 | 支点、轨迹与对手回应 | 镜头与承接 |
| --- | --- | --- |
| immortal-sword.01 引气附锋 | 握剑稳住重心，能量从手部沿剑身汇聚；对手观察蓄势并前移施压 | 近景看能量来源，回中景保留双方距离 |
| immortal-sword.02 凝锋短刺 | 刃尖凝出短剑芒，踏步带实体剑直刺；对手偏转剑身，剑芒沿偏向落空 | 中景看实体与光芒一致，结束回收剑尖 |
| immortal-sword.03 离刃弧斩 | 挥剑先产生实体弧线，再从刃缘放出单道弧形剑气；对手下潜让过 | 中全景看出射、飞行与落空方向，剑气击到后方障碍才散 |
| immortal-sword.04 贴地游锋 | 剑尖贴近地面向前引出一道低位剑气；敌人跃起避让，碎屑沿路径依次掀起 | 斜俯全景，转向要由持剑者动作或既定追踪能力控制 |
| immortal-sword.05 挑浪升剑 | 剑由下向上带出上升气流，掀起对手面前的水或尘；对手后退避开上升范围 | 中全景看下方生成与上升终点，不把对手自动吸入 |
| immortal-sword.06 回锋护环 | 角色转身带剑气形成半环防线，来袭攻击撞开一处缺口；角色随之退步 | 中景斜侧，护环半径与剑路对应，破口跨镜保留 |
| immortal-sword.07 单剑御行 | 手中剑离手后悬在身前，再沿手势指向飞出；对方格开飞剑 | 全景保留人与剑，离手期间角色手中为空 |
| immortal-sword.08 飞剑折返 | 飞剑越过目标后按控制手势走外侧弧线返回；对手转向拦截回程 | 俯斜全景看完整回程，避免剑穿过主人 |
| immortal-sword.09 双路夹击 | 两把已登记的飞剑分走上下路径，敌人移动到两线之间的空档 | 全景画清两路与避让，不让未出场飞剑突然增加 |
| immortal-sword.10 三点封位 | 三把飞剑停在可见节点，依次逼近封住退路；对手击偏一剑打开出口 | 全景交代三角结构，破口后阵形随之变化 |
| immortal-sword.11 环剑护身 | 数把飞剑沿明确环轨运行，外来攻击使其中一把偏离；角色补位或撤离 | 中全景保留人物轮廓，不能把旋转光圈当无敌护盾 |
| immortal-sword.12 层叠剑墙 | 飞剑分层竖列成盾面，对手重击打碎外层，内层后移承压 | 先全景建立厚度再近景看接触，碎剑残片落下 |
| immortal-sword.13 剑雨落区 | 上空剑影先汇聚再向指定区域依次坠下；对手沿未覆盖路线冲出 | 远景显示范围边界，角色与建筑作尺度参照 |
| immortal-sword.14 剑阵收圈 | 外围剑阵节点向中心移动，敌人突击薄弱一侧；施术者调整手势付出控制时间 | 俯拍看圈径缩小和突破口，避免阵法瞬间封死全图 |
| immortal-sword.15 阵眼换位 | 主剑移到新的阵眼，其他飞剑依次转向；对手抓住转向间隙接近施术者 | 全景看阵眼路线，转向有先后而非全部瞬移 |
| immortal-sword.16 御剑升空 | 角色先踏上稳定悬浮剑身，再随剑上升；敌人仰头追踪或跃向高台 | 全景看上剑与升高，脚与剑的相对位置稳定 |
| immortal-sword.17 俯冲回斩 | 御剑下降形成清楚弧线，角色挥出剑气后拉升；敌人侧移，斩线击中地面 | 远全景看俯冲、攻击与拉升，不在触地瞬间凭空倒转 |
| immortal-sword.18 借云隐锋 | 飞剑进入已有云层，轨迹以云流扰动暗示；对手观察云口准备接挡 | 大全景保留云层边界，出云位置承接进入方向 |
| immortal-sword.19 破云一线 | 持剑者压缩剑气后向上斜挥，窄光线贯开云层；敌人以护盾接住余波 | 远景给角色和云层尺度，裂隙沿斩线延展后闭合 |
| immortal-sword.20 星坠重剑 | 空中巨型能量剑先成形再下坠，敌人逃出落区或以阵防御；地面按落点塌陷 | 大全景展示蓄势与逃离时间，近景只用于撞击后的角色反应 |
| immortal-sword.21 龙形缠剑 | 能量沿实体剑路卷成龙形轨迹，盘绕目标周围；对手斩断一段后脱离 | 全景交代环绕方向，龙形随剑势改变而非独立乱飞 |
| immortal-sword.22 莲华分锋 | 中心剑芒分成花瓣状辐射刃，敌人从两瓣间穿出；未命中刃在外缘消散 | 俯斜全景看分裂点与间隙，保留能量数量变化 |
| immortal-sword.23 破空裂斩 | 允许空间能力时，挥剑划开一条短暂裂口，敌人避开裂口覆盖区域 | 全景先定位裂口，再近景看边缘变化；闭合后恢复空间连续 |
| immortal-sword.24 万剑归流 | 已有剑群从不同节点收拢为同向剑流，对手沿汇聚前的间隙撤出或集中抵挡 | 大全景看汇聚过程与目标，不凭空把实体佩剑复制成无数把 |
| immortal-sword.25 一剑收境 | 前段剑阵与剑气向主剑收回，角色以简短挥剑结束战局；对手防线破开或停止进攻 | 先看力量回收再看单次动作，余波渐退并保留破坏地形 |

## 编排与检查

近身对决：引气附锋 → 凝锋短刺被化开 → 回锋护环 → 离刃弧斩。追逐：单剑御行 → 飞剑折返 → 御剑升空 → 俯冲回斩。群战：三点封位 → 对手破节点 → 阵眼换位 → 万剑归流。

强招先给成立条件：距离、蓄势、阵眼或对方破绽。镜头尺度随范围扩大，近景用于角色意图与接触，大全景用于阵形和地貌变化。写清战后实体剑归属、剑影消散、角色落点和仍然存在的裂缝；避免“所有光同时爆炸”替代结果。
