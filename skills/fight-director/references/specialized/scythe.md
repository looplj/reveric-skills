# 长柄镰刀：控距、回收与空间调度

先锁定长柄、横向弯刃和持握位置，保持同一把实体兵器。写实质感模式不附加自动回收、锁链、分身或无来源飞行；幻想能力由角色卡单独说明。

## 动作库

| 编号／动作 | 动作、轨迹与对手回应 | 镜头与后续状态 |
| --- | --- | --- |
| scythe.01 横架迎挡 | 双手分握使柄横在身前，接住来械后随冲力退步；对方回收兵器准备再进 | 中景斜侧，柄弯曲或手臂震动与力量一致 |
| scythe.02 外弧扫挡 | 腰带长柄划出外侧大弧，迫使对方后撤避开弯刃 | 全景保留完整刃路，收势时刃停身侧 |
| scythe.03 低位掠扫 | 降低重心让刃沿地面上方横移，对方抬步跳离扫线 | 斜俯全景看脚与镰刃间距，错过后沿原惯性回收 |
| scythe.04 斜上挑开 | 柄尾下压带动弯刃斜上升，对方兵器沿接触面滑开 | 中景跟刀头上扬，下一拍双手稳住柄 |
| scythe.05 短柄近挡 | 对手穿入长刃内圈，持镰者收短握距用柄截挡并侧退 | 中景看内圈空档，退开后恢复长柄距离 |
| scythe.06 柄尾点退 | 弯刃在外侧回收时，柄尾短送迫使近身对手停步架挡 | 近景看柄尾接触后立即收回，不凭空换手 |
| scythe.07 钩械牵引 | 镰内弧与对方长兵交叉，转身牵引使来械偏向侧方；对方放松前手顺势解脱 | 近景接触再拉中景，交代是否仍握住兵器 |
| scythe.08 回身返扫 | 外扫落空后，先收柄再转脚回身，让弯刃从新方向横扫；对方沿弧外退走 | 中全景跟身，不用切镜隐藏刃穿过身体 |
| scythe.09 侧移下劈 | 斜侧踏步腾出弯刃空间，长柄向前下方压落；对方撤离，刃击地面 | 全景留落点，泥土或石屑响应后需拔回 |
| scythe.10 跃步落镰 | 蹬地小跃抬起兵器，下降时双手带柄落下；对方以翻滚离开冲击区 | 全景看起落和闪避，不能空中突然反向加速 |
| scythe.11 短掷逼位 | 仅在开阔场地将镰抛向明确落区，对方避让后镰落地；持镰者冲向落点重新取回 | 全景同时保留人、镰、目标；脱手期间不得继续持镰攻击 |
| scythe.12 支柄转位 | 柄尾先触地成为可见支点，身体绕支点跨步转到侧面，弯刃跟着整体移开 | 中全景看支点受力，结束时拔柄并恢复双手握持 |

## 编排与检查

常用链：外弧扫挡逼退 → 对方趁回收贴近 → 短柄近挡侧退 → 斜上挑开恢复距离。终结可以是缴械、击退或压住退路，不必每次劈地。

检查刃形、手距与挥动净空；窄巷里优先缩短动作，不能让横刃穿墙。低位扫和落镰保持对手的躲避路径；抛掷后明确空手期和取回过程。
