# 梦想一心太刀：雷系单刀编排

使用雷电将军的梦想一心战斗形态时锁定单刀与雷光。普通“雷电”原创角色不自动套入这个版本。以下名称用于镜头调度；只有用户给定的超自然能力才进入角色卡。

## 动作库

| 编号／动作 | 动作、轨迹与对手回应 | 镜头与后续状态 |
| --- | --- | --- |
| raiden-tachi.01 显刀起势 | 手部靠近胸前，刀身沿可见出刀路径显现，光向刃面集中；对手压低持械姿态等待 | 近景看起点后拉中景，避免把光幕当作完整动作 |
| raiden-tachi.02 斜步闪斩 | 脚下先侧前移，单刀随转髋走短斜线；对方以兵器挡住，刀光在交点短闪 | 中景斜跟，不出现无因瞬移 |
| raiden-tachi.03 中线疾刺 | 收刀于身前后踏步送出直线；对方偏转刀尖并退出 | 中近景保留对手反应，刺空后刀回中线 |
| raiden-tachi.04 回身横切 | 前一斩落空后顺惯性收腕转脚，再向后侧来敌横切；来敌退开 | 中全景看转身路径，不增加第二把刀 |
| raiden-tachi.05 上架引偏 | 单刀斜上架接住下落攻击，身体侧移引开；对方兵器沿刀面滑走 | 近景看交点，接中景显示新站位 |
| raiden-tachi.06 低位切入 | 屈膝压低姿态从高位攻击下移入，刀路由低向侧上；对方收肘压械应对 | 斜侧中景让低身与刀路同框 |
| raiden-tachi.07 雷痕追步 | 沿已经交代的追击线路加速，脚后留短促光痕；对手穿过障碍，追击者绕行 | 中景横跟，光痕提示路径而非代替路径 |
| raiden-tachi.08 落步垂斩 | 起跳越过低障碍，下降时竖向挥刀；对手退出落区，地表闪出短雷纹 | 全景跟起落，落地后刀尖回收 |
| raiden-tachi.09 连斩换区 | 一次上方斜斩被挡后转向对手兵器侧面，逼其改变防线；第三拍按时间决定是否追击 | 中景侧前跟随，光轨依次消失不堆成光球 |
| raiden-tachi.10 单线破势 | 先以架挡移开对手兵器，再沿形成的空档挥出一条强光斩线 | 先中近景交代破绽，再拉全景看命中与击退 |
| raiden-tachi.11 雷光收束 | 周围短电弧集中到刀刃，角色停步稳定重心；对手利用蓄势间隙后撤 | 低仰中景保留对手，不让蓄力冻结全场 |
| raiden-tachi.12 决断一斩 | 承接已有破绽，身体前移带刀完成一条决定性斩线；对手抵挡失衡或被迫退场 | 中景到全景，雷光沿实体挥刀扩展，结束仍见角色与地面 |

## 编排与检查

组合：显刀起势 → 斜步闪斩被挡 → 上架引偏 → 单线破势。对手持续有动作，神性压迫靠节奏与姿态呈现。

刀形态内不混入长枪、薙刀或枪杆动作；用户要求全形态切换时，单独编排转换。收刀若没有实体刀鞘，可采用垂刀或能量消散，不能凭空多出刀鞘。空间裂纹、瞬移、时停不是默认附赠能力。
