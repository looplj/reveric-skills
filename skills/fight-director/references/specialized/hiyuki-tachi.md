# 绯雪单刀：冷凝与霜樱编排

用户指定《鸣潮》绯雪时采用冷凝属性、迅刀与灼樱巫女方向；用户指定原创火焰刀绯雪时返回原角色卡。未提供外观参考时不编造服装细节。常世／预求双形态、冰弓、时停等细节按用户提供的设定启用，未指定时不自动添加。

## 编排与检查

组合：斜步樱切 → 对手回击 → 霜面接挡 → 停拍反斩 → 贴地霜滑退出。粉色用于樱瓣意象，冰蓝用于冷凝材质，不自动把粉樱当火焰。

若用户确实指定临时冰弓，明确单刀当时的位置、冰弓形成与消散，再回到持刀状态；双形态切换同样写清触发、姿态、色彩与结束状态。用户指定游戏技能名时沿用其名称；表内名称用于镜头编排。
