# 输出格式

用户指定格式、时长和字数时按要求输出；未指定时生成15秒打戏，采用精简格式。

## 精简模式（默认）

适合单段打戏，正文控制在约2000中文字符内。按动作需要分段；模板中的说明替换成真实内容，无参考素材时省略素材引用。

```text
标题与总时长
全局：视觉风格、画幅（如已指定）、材质、光色与声音。
角色：身份／参考绑定、外观锚点、主战手段、动作签名与特效颜色。
场景：空间地点、初始关系、可利用地形与环境细节。

0–t1秒｜景别·视角／角度·运镜·跟随目标
动作起因与位移；A攻击的路径和目标；B的防守／闪避／受击与反击；
接触反馈、环境响应和声音；结束时双方的新姿态与位置。

t1–t2秒｜下一段镜头规格
承接上段状态，展开下一组攻防，推进主动权变化。

末段至总时长｜终结镜头规格
破绽或机会如何形成、决定性动作、对方反应、结果与余波。
必要约束：仅保留本任务真正需要的外观、兵器、空间和生成限制。
```

## 详细模式

适合群战、复合技能、多阶段场景或完整视听方案，正文控制在约5000字符内。删除不适用字段，不生成不存在的图或角色。

```text
【作品标题】总时长｜参战角色｜战斗主题
GLOBAL SETTINGS｜全局规格：风格、画幅、材质、光色、节奏。
VFX LOCK｜角色、武器、能力、动作签名、特效颜色与材质。
REFERENCE LOCK｜实际提供的素材与人物／场景绑定（无素材则省略）。
SOUND LOCK｜动作、碰撞、环境声；仅保留用户要求的对白和音乐。
BATTLE CORE｜目标关系、初始距离与位置、主要攻防链、结束条件。
TIMELINE｜从0开始首尾相接的时间段：
  镜头编号与标题
  摄影参数：景别、观察角度、运镜、跟随目标；按需要加焦段等。
  入镜承接：上段动作或声音怎样进入本段。
  空间与攻防：位置、路径、攻方动作、目标、守方反应、反击／追击。
  技能与反馈：生成位置、释放、轨迹、命中、角色受力、材质响应。
  视听与结束状态：可见重点、声音、破坏残留、新姿态与下一段承接。
CORE GOAL｜本段最终可见的战斗结果。
FINAL HARD CONSTRAINTS｜真正需要锁定的角色、能力、空间及禁止项。
```

不用在每个字段重复相同的全局规则。压缩时先删重复形容词和重复声明，保留动作因果、空间变化、回应、命中反馈和结果。自然声音默认保留，背景音乐、旁白、字幕依用户要求安排。

## 时间预算

先为接近、交锋、换位、转折和结果分配时间，再确定镜头数量。慢动作、定格和余波都计入总时长。动作放不下时删减重复招式；较长战斗按主动权或空间变化划分片段，片段之间承接角色与场景状态。

例如15秒逆转打戏：0–2秒进攻接触，2–5秒近身拆招，5–9秒逼退追击，9–12秒发现破绽并反击，12–15秒决定性动作与结果。若需要蓄势对峙，压缩重复交锋，把时间留给双方观察和抢先手；若是一镜到底，保持这些动作节拍，用连续运镜交代换位。

时间轴从0开始，镜头首尾相接，最后一镜结束于指定总时长。
