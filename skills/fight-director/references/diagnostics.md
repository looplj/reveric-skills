# 局部诊断与修复

先定位问题段，保留有效设定；修改后检查相邻段的开始与结束状态。

| 症状 | 优先修复 |
| --- | --- |
| 两人站桩轮流出招 | 加入接近、逼退、侧向追击、地形借力；每次攻击有回应 |
| 打得快但看不清 | 减少同段动作和运镜，放大关键动作景别，保留完整路径 |
| 打击像擦过 | 写明接触位置、方向、对方身体响应与惯性后果 |
| 破防后立即满状态 | 插入失衡、仓促拍挡、闪避或恢复重心的过渡 |
| 摔投后人物凭空站起 | 交代落地姿态、控制关系、脱身或起身路径 |
| 人物突然换侧／换高度 | 补移动原因、路线与落点，用环境锚点解释机位变化 |
| 兵器变形或能力串台 | 锁定兵器数量、持握手与实体形态，删除不相容技能 |
| 特效遮住攻防 | 减少粒子，沿实体轨迹呈现；只在关键命中强化 |
| 法术像静态贴图 | 增加生成、结构变化、内部流动、目标反馈和消散 |
| 环境下一镜恢复原状 | 延续裂缝、积水、碎片与遮挡，更新可通行路线 |
| 写实格斗出现玄幻爆炸 | 改用鞋底摩擦、衣料震动、汗滴、尘土与受力反馈 |
| 字数或时长超限 | 减少支线技能和重复说明，保持主攻防链完整 |

仅用户提供视频或帧图时才能判断实际成片；否则明确诊断对象是提示词文本，不声称已验证生成效果。
