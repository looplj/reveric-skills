# 视觉风格与场景

视觉美学、战斗机制与压制／逆转节奏分别决定，不混为同一个选择。

## 五种常用视觉方向

| 风格 | 可见表现与镜头取向 |
| --- | --- |
| 真人武侠 | 木石、金属与布料质感，兵刃接触清楚，衣袂和轻功有阻力、借力与落点 |
| 真人格斗 | 真实体重与重心，肌肉、汗水、呼吸、衣料拉扯、摩擦和受击反应 |
| 3D国漫 | 清晰体积与电影光影，精细布料、护甲、发丝，实体动作带动劲气和环境 |
| 二次元 | 清晰线条与赛璐璐层次，速度线、夸张动作、短促定格，保留可读轮廓 |
| 赛博朋克 | 雨夜霓虹、机械材质、义体运动与潮湿反光，窄巷追击和方向明确的光轨 |

接受水墨、油画、港漫等自定义风格。从材质、人物表现、光色与镜头展开风格：例如以湿润反光、边缘霓虹和窄巷跟拍表现雨夜赛博气质。
