## 17. 法术型技能元素体系与角色绑定

法术型技能作为“战斗手段”和“力量来源”的专项子系统，分为风、火、水、雷、土、木、冰、金、光、暗十个元素系。元素本身不是角色职业，必须与角色职业、战斗定位、力量来源和战斗机制绑定后，才能编译成可执行的打斗动作。

同一种元素由不同职业使用时，动作形态、释放方式、战斗距离、镜头重点和环境反馈必须不同。例如“火球”：法师以施法蓄力和投射为主，枪械师表现为火焰弹药，格斗家表现为火焰拳，召唤师表现为火龙或火灵召唤，控制师表现为持续燃烧区域。

### 17.1 风系技能

**核心技能形式：**风刃、龙卷、气流、风暴、空气压缩、飓风领域。

**主适配职业：**法师系中的风元素法师、特殊法则与概念系中的气流/空气操控者。

**辅助适配职业：**格斗家系、刺客与潜行系、弓弩与投射系、兵器大师系、变身与强化系。

**推荐复合职业：**风行刺客、风刃剑士、风暴术师、御风武僧。

**战斗定位：**高速移动、远程切割、位移扰乱、范围控制、空中追击。

**推荐机制：**纯技能型、体术＋技能型、兵器＋技能型、环境操控型。

**绑定规则：**刺客使用风系时重点表现无声突进和风刃切割；格斗家表现为风步、气流推动和旋身打击；弓箭手表现为改变弹道和风压箭；兵器大师表现为风刃剑气或长枪气流；法师才默认使用大范围龙卷、风暴和飓风领域。

### 17.2 火系技能

**核心技能形式：**烈焰、火球、火龙、熔炎、火雨、爆燃冲击。

**主适配职业：**法师系中的火元素法师、变身与强化系中的火焰变身者。

**辅助适配职业：**格斗家系、兵器大师系、召唤与御兽系、枪械与科技系、特殊法则与概念系。

**推荐复合职业：**战斗法师、火焰拳师、炎刃剑士、火龙召唤师、爆燃枪斗士。

**战斗定位：**爆发输出、范围清场、持续灼烧、破坏掩体、压迫推进。

**推荐机制：**纯技能型、体术＋技能型、兵器＋技能型、召唤操控型、环境操控型。

**绑定规则：**火系必须表现热源、亮度、烟尘、燃烧对象和冲击结果；火龙属于召唤或高阶技能，不应作为普通火球的无因果升级；枪械与科技系只有在魔导武器、燃烧弹或科技能源设定成立时才使用火系法术表现。

### 17.3 水系技能

**核心技能形式：**水刃、水龙、漩涡、洪流、巨浪、水牢、潮汐。

**主适配职业：**法师系中的水元素法师、治疗与辅助系、诅咒与控制系。

**辅助适配职业：**召唤与御兽系、防御与守护系、特殊法则与概念系、弓弩与投射系。

**推荐复合职业：**水疗术师、水牢控制师、潮汐召唤师、水盾守护者。

**战斗定位：**持续输出、束缚控制、护盾防御、治疗净化、地形改变。

**推荐机制：**纯技能型、召唤操控型、环境操控型、兵器＋技能型。

**绑定规则：**水系要明确水源、流向、压力、体积和落点；治疗辅助优先使用水流、净化和护盾，不自动变成洪水攻击；控制师重点使用水牢、漩涡和潮汐限制移动；召唤师可使用水龙或水灵协同作战。

### 17.4 雷系技能

**核心技能形式：**雷击、电弧、雷枪、雷网、雷霆风暴、雷电附体。

**主适配职业：**法师系中的雷元素法师、格斗家系、特殊法则与概念系。

**辅助适配职业：**刺客与潜行系、枪械与科技系、兵器大师系、变身与强化系。

**推荐复合职业：**雷霆武僧、雷光刺客、电磁枪手、雷枪剑士、雷电变身者。

**战斗定位：**瞬间爆发、高速位移、麻痹打断、远程穿透、链式攻击。

**推荐机制：**纯技能型、体术＋技能型、热兵器型、兵器＋技能型、变身强化型。

**绑定规则：**雷系动作必须交代蓄能、放电方向、接触点、传导路径和命中后的麻痹/击退结果；刺客和格斗家优先使用雷电附体与短距离爆发，法师才默认展开雷霆风暴和雷网领域；科技角色的雷系应表现为电磁、电弧或高压武器，不能无依据写成魔法雷法。

### 17.5 土系技能

**核心技能形式：**岩刺、石墙、地震、山岳、流沙、岩石巨人。

**主适配职业：**法师系中的土元素法师、防御与守护系。

**辅助适配职业：**召唤与御兽系、诅咒与控制系、兵器大师系、特殊法则与概念系。

**推荐复合职业：**岩甲守护者、山岳术师、岩石巨人召唤师、流沙控制师。

**战斗定位：**防御承伤、阵地建立、地形改造、范围震荡、重型压制。

**推荐机制：**纯技能型、环境操控型、召唤操控型、机械装备型、兵器＋技能型。

**绑定规则：**土系必须表现地面、岩石、重量、裂缝、塌陷和阻挡关系；守护者优先使用石墙、岩甲和地面防线；控制师优先使用流沙和地震改变站位；岩石巨人属于召唤或高阶塑形，不应脱离地面凭空出现。

### 17.6 木系技能

**核心技能形式：**藤蔓、树根、花瓣、花海、植物生长、木灵召唤。

**主适配职业：**法师系中的自然/植物法师、召唤与御兽系、治疗与辅助系。

**辅助适配职业：**诅咒与控制系、防御与守护系、变身与强化系。

**推荐复合职业：**木灵御兽师、花海控制师、自然治愈师、藤蔓守护者。

**战斗定位：**束缚控制、持续生长、召唤协同、治疗恢复、区域封锁。

**推荐机制：**纯技能型、召唤操控型、环境操控型、变身强化型。

**绑定规则：**木系要表现种子/根系来源、生长方向、缠绕对象和植物与环境的关系；治疗辅助重点使用生长、修复和净化；控制师重点使用藤蔓、树根和花海封锁；召唤师可召唤木灵或植物兽，不把普通植物生长直接写成独立生命体。

### 17.7 冰系技能

**核心技能形式：**冰锥、冰晶、霜冻、冰封、暴风雪、寒冰领域。

**主适配职业：**法师系中的冰元素法师、诅咒与控制系、防御与守护系。

**辅助适配职业：**弓弩与投射系、兵器大师系、刺客与潜行系、特殊法则与概念系。

**推荐复合职业：**冰霜射手、寒冰剑士、冰封控制师、冰晶守护者。

**战斗定位：**减速控制、冻结限制、精准穿刺、护甲防御、范围封锁。

**推荐机制：**纯技能型、兵器＋技能型、环境操控型、体术＋技能型。

**绑定规则：**冰系必须表现降温、结晶、冻结进程、地面结霜和受击后的动作减速；弓箭手适合冰晶箭和冰锥；兵器大师适合冰刃和冰甲；控制师适合冰封和寒冰领域；不把冰系默认写成大规模暴风雪，除非角色能力和场景尺度支持。

### 17.8 金系技能

**核心技能形式：**金属操控、万剑齐发、金属风暴、金甲、金属巨像。

**主适配职业：**兵器大师系、枪械与科技系、法师系中的金属/炼金法师。

**辅助适配职业：**防御与守护系、召唤与御兽系、特殊法则与概念系。

**推荐复合职业：**金属剑师、机械操控师、金甲守护者、金属巨像召唤师、炼金战士。

**战斗定位：**武器操控、远程齐射、装甲防御、机械构装、重型压制。

**推荐机制：**兵器＋技能型、机械装备型、召唤操控型、纯技能型、环境操控型。

**绑定规则：**金系必须有明确金属来源、数量、形态和操控方向；兵器大师优先表现剑阵、金属刃和武器变形；科技角色优先表现机械零件、无人机和金属装甲；金属巨像属于构装体或召唤体，需要交代组装、移动和受损反馈。

### 17.9 光系技能

**核心技能形式：**圣光、光束、光刃、光翼、光之领域、净化冲击。

**主适配职业：**治疗与辅助系、防御与守护系、法师系中的光元素法师。

**辅助适配职业：**特殊法则与概念系、兵器大师系、召唤与御兽系、变身与强化系。

**推荐复合职业：**光明圣骑士、圣光治愈师、光翼战士、净化术师、圣剑士。

**战斗定位：**治疗恢复、护盾守护、净化驱散、远程贯穿、领域增益。

**推荐机制：**纯技能型、环境操控型、兵器＋技能型、体术＋技能型、变身强化型。

**绑定规则：**光系必须区分照明、攻击、治疗、净化和领域增益；圣职者和辅助师优先使用圣光、净化冲击和光之领域；圣骑士可将光系绑定剑盾与护甲；光束或光刃作为高杀伤技能时必须明确发射方向、遮挡关系和命中反馈。

### 17.10 暗系技能

**核心技能形式：**暗影、黑雾、暗刃、影子束缚、深渊漩涡、黑暗领域。

**主适配职业：**诅咒与控制系、刺客与潜行系、法师系中的暗影/黑暗法师。

**辅助适配职业：**召唤与御兽系、变身与强化系、特殊法则与概念系、格斗家系。

**推荐复合职业：**暗影刺客、深渊术师、黑雾控制师、暗影召唤师、影武者。

**战斗定位：**隐身突袭、削弱诅咒、视线遮蔽、束缚控制、持续领域压迫。

**推荐机制：**纯技能型、体术＋技能型、召唤操控型、环境操控型、变身强化型。

**绑定规则：**暗系必须交代暗影来源、遮蔽范围、影子与目标的关系以及领域边界；刺客优先使用暗影、暗刃和影子位移；控制师优先使用黑雾、影子束缚和黑暗领域；深渊漩涡属于高阶空间/领域效果，需要明确吸引方向和环境反馈，不能只作为装饰光效。

## 18. 元素技能与角色职业的绑定矩阵

绑定时优先按照“主职业决定施法动作，元素决定技能形态，战斗定位决定战术用途”的规则生成。

| 角色职业 | 优先元素 | 典型绑定方式 |
|---|---|---|
| 格斗家系 | 火、雷、风、土、暗 | 火焰拳、雷电附体、风步、地震拳、暗影强化 |
| 法师系 | 风、火、水、雷、土、木、冰、金、光、暗 | 元素投射、元素领域、元素召唤、复合元素法术 |
| 兵器大师系 | 火、雷、冰、金、风、光、暗 | 火刃、雷枪、冰剑、金属操控、风刃剑气、圣剑、暗刃 |
| 枪械与科技系 | 火、雷、金、光、冰 | 火焰弹、电磁枪、金属武器、光束炮、冷冻弹药 |
| 弓弩与投射系 | 风、火、水、雷、冰、光、暗 | 风压箭、火焰箭、水刃箭、雷枪箭、冰晶箭、光箭、暗影箭 |
| 刺客与潜行系 | 风、雷、冰、暗 | 风步、雷光闪身、冰封刺杀、影子束缚、暗刃 |
| 召唤与御兽系 | 火、水、土、木、光、暗 | 火龙、水龙、岩石巨人、木灵、光灵、亡灵/暗影召唤 |
| 防御与守护系 | 土、金、冰、水、光 | 石墙、金甲、冰盾、水牢防线、光之领域 |
| 治疗与辅助系 | 水、木、光、冰 | 水流治疗、植物生长、净化圣光、冰霜护盾 |
| 诅咒与控制系 | 水、土、木、冰、暗、风 | 水牢、流沙、藤蔓、冰封、黑雾、飓风领域 |
| 变身与强化系 | 火、雷、金、木、光、暗 | 火焰化、雷电附体、金甲、木灵化、光翼、暗影化 |
| 特殊法则与概念系 | 风、雷、冰、光、暗及复合元素 | 空气压缩、雷电法则、寒冰领域、光之领域、现实扭曲 |

该矩阵是默认推荐，不是硬限制。用户明确指定元素或职业时，用户选择优先；AI 只负责把选择转译成符合职业动作和战斗逻辑的表现。

## 19. 法术型技能的生成链

所有元素法术必须经过完整因果链，不得只堆叠技能名称：

```text
元素来源
→ 施法/蓄能动作
→ 元素形态
→ 释放方向与运动轨迹
→ 与角色、武器、召唤物或环境的关系
→ 接触/命中结果
→ 目标反应
→ 场景反馈
→ 余波、持续状态或消散
```

例如“雷霆武僧”不能只写“释放雷电”，而应表现为重心下沉、拳臂蓄能、电弧沿手臂聚集、近身击中目标、雷电传导造成麻痹和击退、地面留下短暂电痕，最后电弧消散。

## 20. 元素组合规则

用户可以指定单元素、双元素或多元素法术。默认规则如下：

- 4–15 秒片段默认选择一个主元素，最多增加一个辅助元素。
- 16–30 秒片段可以增加第二个元素的独立节拍，但仍需保持主元素视觉中心。
- 多元素必须有明确的生成关系，不得把元素名称并列堆在一起。
- 常见可解释组合包括：火＋风形成爆燃风暴，水＋冰形成冻结洪流，雷＋金形成电磁金属风暴，木＋水形成植物洪流，光＋暗形成净化与侵蚀对冲。
- 若两个元素会产生明显冲突，必须说明是相克、融合、轮换还是敌我双方分别使用。
- 元素数量增加不能替代动作设计；每个元素都必须服务角色定位、攻击目的或环境反馈。

## 21. 角色档案新增元素字段

在原有 `【角色战斗档案】` 中增加以下字段：

```text
法术类型：无 / 法术型 / 复合型
主元素：……
辅助元素：无 / ……
元素职业：……
法术具体形式：……
元素战斗定位：输出 / 控制 / 防御 / 治疗 / 召唤 / 强化 / 领域 / 其他
元素来源：修炼 / 魔法 / 神力 / 科技 / 血脉 / 契约 / 装备 / 法则 / 其他
元素限制与代价：……
元素与角色武器的关系：……
元素与环境的关系：……
```

最终提示词只提取当前镜头需要的元素字段，不复制完整元素库；角色能力和元素类型很多时，优先保留主元素、主战斗行为和一个明确的命中/环境结果。
