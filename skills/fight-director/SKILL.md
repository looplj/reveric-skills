# 打斗导演

把战斗需求编译为有攻防因果、角色辨识度、空间连续性和可见反馈的视频提示词。只负责创作文本，不自动提交视频生成任务。

## 先确定任务

- 生成打戏：提取角色、场景、视觉风格、战斗机制、时长、结局、参考素材与禁止项，直接编排。
- 创建角色：建立外观锚点、主战手段、破招方式、终结方式、动作签名、特效主色与能力限制；已指定的武学和武器不再询问。
- 推荐风格、场景、武学：只展示相关选项；用户授权代选时直接选择并继续，不强迫走菜单。
- 修复提示词：保留已确定的角色、结果与有效镜头，只修复问题段及相邻衔接。

信息不足但可合理补全时采用最少假设。缺失的对手、胜负或参考身份会改变核心任务时才提问；没有上传素材时，不虚构“图一”“@角色”等平台引用。

## 统一编排流程

1. **锁定事实。** 区分用户事实与创作补充；参考素材只约束实际可见信息。记录各角色的形态、武器与持握手、力量来源、限制、目标关系和结束条件。
2. **选定表现。** 分别选择视觉风格、战斗机制、叙事节奏（压制／拉锯／逆转）。先确定主要手段，再选少量能衔接的技能；不为凑技能数给角色添加不相容能力。
3. **建立空间。** 记录初始距离、高度、朝向、障碍、可达区域、借力点与可破坏材质。角色位置允许改变，每次换位都有路径、原因、落点和后续动作。
4. **先写动作骨架。** 起势／接近 → 攻击 → 对手防守、闪避或受击 → 反击／追击 → 新位置与状态 → 下一轮 → 结果。多人战斗明确每次攻击的对象，以及其他角色当时在做什么。
5. **加入节奏与摄影。** 根据动作分配时间。短打可用开局接触、近身交锋、空间变化、情绪拐点、终结的结构；不机械套用。摄影描述包含景别、视角／角度、运镜和跟随目标，重点动作完整可见。
6. **加入视听反馈。** 身体或武器发力 → 轨迹 → 接触 → 对方反应 → 环境响应。特效写清生成位置、形成、运动、交互和消散；声音与碰撞、脚步、材质、空间一致。
7. **编译并检查。** 按输出格式生成可复制正文，检查时间、状态和字数。除用户请求解释外，不输出候选评分、内部状态表、公式编号或自检过程。

内部只需维护：角色当前姿态／位置／速度／目标、武器与技能状态、防守与受击状态、场景破坏、摄影机观察方向、下一段承接。上一段结束状态必须成为下一段起点。

## 核心动作与镜头规则

- 每次主要攻击都要有可见回应。把“高速连击”展开为具体动作、轨迹、目标与应对；连招之间交代重心转移和回收，避免无过程换姿势。
- 破防之后保留失衡或仓促防守的过渡，不能下一帧恢复完整格挡。擒拿、摔投之后交代控制、脱身、追击或起身。
- 小幅手法用中近景／近景，大幅旋转、投摔、腾跃用能容纳全身和路径的景别；特写强调破绽或接触点，不遮断动作原因。
- 快速交锋优先方向明确的跟拍、小幅横移与短推拉。环绕、快切、慢镜和定格都需要叙事目的，不为数量指标改变镜头。
- 跨轴或换方向可通过连续运动、中性机位、环境锚点或重新交代站位实现；不能把自由位移写成无因瞬移，也不能全程固定左右站桩。
- 特效跟随角色与动作，不替代实体交锋。沿用角色主色，保留冷暖／明暗对比；写实模式用汗水、衣料、尘土、雨滴与惯性反馈，不强加能量波和建筑毁灭。
- 大范围技能保留尺度参照，并让破坏影响后续路线；裂缝、失去的武器、疲态等跨镜延续。终结结果符合用户要求，可以击败、撤退、僵持或留悬念。

## 模式选择与优先级

用户明确要求优先，其次采用本文件的统一规则；reference 中的格式、次数、时长与镜头限制按对应模式选用：

- **时长与格式：** 默认 15 秒精简提示词，建议约 2000 中文字符内；复杂多角色场景可选详细格式，建议 5000 Unicode 字符内。4–30 秒为常用创作区间，不宣称是平台硬限制。用户指定格式、时长、字数优先；更长作品按片段规划。
- **动作密度：** 以时间内可读、可完成为准。多技能是丰富战斗的方法，不能覆盖用户指定的单招对决；不强制每个人每段使用两招。
- **风格与强度：** 肘击、腾空、夸张闪避、残影、气爆和史诗破坏按角色与风格选择，不强加到所有打斗。
- **镜头与结尾：** 不固定两秒一切、固定机位角度或一律高潮截断；用户指定一镜到底、平静收势和自然余波均可执行。角度可描述清楚后按需要量化。

## 交付前检查

确认角色与参考身份不漂移；每击有回应；位移与防守恢复有过程；镜头能看清关键动作；特效与破坏有来源；时间轴从零连续到指定终点；结局与用户约束一致；没有空占位符、虚构素材引用或无关说明。
