# 镜头索引

打戏只从等级 A 里挑，打法要和本段一致：一对一、一打多或以小打大。等级 B 只看打法，不整句搬。等级「衔接」只用于登场、对峙、变身和收刀。

选中编号后，打开对应文件，整句搬英文，只换人名、武器、颜色和场景物件。

默认六个位置：0 秒开场爆发或对冲交锋，1 秒近身快打，4 秒三连、腾空、空中或对撞，7 秒特写或闪避，10 秒硬接或缴械，12 秒收尾、锁刀或落地对峙。
