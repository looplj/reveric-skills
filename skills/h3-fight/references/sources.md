# 来源

库里每条来源提示词：等级、打法、风格、为什么收。等级 A = 出片后人工看过、认为好的；B = 出过片但写法偏短，只当打法参考；衔接 = 好片子里的非打斗镜头（登场、对峙、收刀）。成片不随仓库发布。日漫 A/B/C 是 2D 日漫徒手对打测试，人物、招式名、外形已经去掉，只留写法。

完整来源提示词在上游 `库/来源/`。本技能只收三条全文作六段式范例：[k4d](examples/k4d.md)、[C1](examples/c1.md)、[日漫C5](examples/anime-c5.md)。镜头英文已拆进 [镜头索引](shot-index.md)。
